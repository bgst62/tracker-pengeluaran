# Tracker Pengeluaran

Aplikasi web sederhana yang bisa mencatat pengeluaran harian dengan kategori berbeda

🔗 **Demo** : https://bgst62.github.io/tracker-pengeluaran/

## Fitur
- Tambah pengeluaran
- Hapus pengeluaran
- Total pengeluaran otomatis terhitung
- Data tidak hilang saat direfresh (Localstorage)

## Tech stack
- HTML
- CSS
- Javascript (vanilla, tanpa framework)
- localStorage untuk menyimpan data

## Cara menjalankan
- Clone repo ini
- Lalu buka 'index.html' dibrowser

CRUD dasar, DOM Manipulation, Event Handling
